# 玄枢使用指南

从首页选择一种术数，填写输入并生成结果。玄枢无需账户、API Key 或数据库；排盘在浏览器内计算，完成后自动尝试保存到本机记录。

[返回项目介绍](../README.md) · [自行部署](deployment.md)

## 跟着示例试一次

以下均为公开演示用的虚构输入，不对应真实用户。日期使用公历，时间使用 24 小时制。

| 方法 | 演示输入 | 提交按钮 | 可以观察的结果 |
| --- | --- | --- | --- |
| 六爻 | 问题：`近期如何安排学习计划？` | 开始起卦 → 查看卦象 | 三钱六掷、本卦与变卦、动爻、爻位明细 |
| 四柱八字 | `1990-06-15` · `12:00` · 男 · `00:00 换日` · 流年 `2026` | 开始排八字 | 庚午、壬午、辛亥、甲午四柱；日主辛 |
| 紫微斗数 | `1990-06-15` · `12:00` · 男 · 流年 `2026` | 生成紫微命盘 | 火六局、贪狼命主、火星身主；十二宫与流年叠盘 |
| 梅花易数 | 第一数 `17` · 第二数 `28` | 依数起卦 | 天雷无妄 → 天火同人；三爻动，互卦风山渐 |
| 小六壬 | `2026-10-01` · `12:00` | 开始起课 | 八月廿一、午时；月落留连、日落赤口、时落赤口 |

六爻每次起卦使用随机铜钱结果，相同问题不会固定得到同一卦。其余四门在相同输入与取法下生成相同结果。

## 六爻：从问题到卦象

1. 在“所问之事”填写一个具体问题，去除首尾空格后至少 2 个字符，最多 80 个字符。
2. 点击“开始起卦”。六次铜钱动画会自动依次完成，无需逐次点击；卦象在开始时已锁定，动画只展示结果。
3. 完成后点击“查看卦象”，查看本卦、变卦、动爻，以及卦宫、世应、月建和日辰。
4. “爻位信息”列出六亲、六神、纳甲与动爻；展开“完整排盘数据”可查看起卦时间、时区、原始爻值和规则版本。

要重新开始，可在起卦完成后点击“重新起卦”，或在结果页点击“再起一卦”。月建按固定北京时间的节气计算，日辰按起卦会话的时区计算。

## 四柱八字：四柱、明细与流年

1. 输入公历出生日期、**北京时间 UTC+8** 和性别。
2. 展开“排盘选项”，选择 `00:00 换日` 或 `23:00 换日`，并填写要查看的流年。
3. 点击“开始排八字”。四柱按年、月、日、时从左到右排列，十神以日主为参照。
4. 展开“四柱明细”查看藏干十神、十二长生与旬空；继续向下查看五行计数、胎元、命身宫、起运、大运和所选流年。

出生日期支持 1900—2100 年，流年须在出生公历年份至 2100 年之间。年柱、月柱以节气换界；晚子时的时柱统一按次日子时排定。五行图只统计四柱八个表层干支，不代表旺衰或喜用神。当前不做出生地和真太阳时校正。

## 紫微斗数：点选宫位查看星曜

1. 输入公历出生日期、钟表时间和性别。
2. 只看本命盘时可直接提交；需要年度视图时，展开“流年叠盘”并填写年份。
3. 点击“生成紫微命盘”，查看十二宫、命身主和五行局。
4. 点击任一宫位，其下方详情会更新为该宫的主星、辅星、杂曜、亮度和生年四化。填写流年后，还可查看叠加的流年宫位、星曜、四化和大限。
5. 展开“十二宫总览”可逐宫查看完整星曜，并跳转到宫位详情。

出生日期和流年支持 1900—2100 年，流年不能早于出生农历年。23:00—23:59 按次日早子时安星；闰月初一至十五按当月，十六日起按下月。年度视图使用所选公历年 7 月 1 日为参考日，虚岁和大限对应此日。旧版晚子时记录会显示取法提示，重新提交按当前规则计算。

## 梅花易数：双数起卦

1. 输入两个 `1—999999` 之间的整数，第一数定上卦，第二数定下卦。
2. 点击“依数起卦”，查看本卦、变卦、动爻、互卦和体用。
3. 在“计算留痕”中核对两个数与动爻的对应关系。

上下卦除以 8 取余，余 0 作 8；两数之和除以 6 取动爻，余 0 作 6。动爻所在的三爻卦为用卦，另一个为体卦。当前只提供双数起卦，不包含其他起卦方式或自动断语。

## 小六壬：按月、日、时顺推

1. 输入事情发生或准备决断的公历日期与钟表时间；“使用当前时间”可填入设备当前时间。
2. 点击“开始起课”，查看月宫、日宫与最终时宫。
3. 在“六宫次序”和“计算过程”中核对六宫顺序、农历月份、日数和时辰的逐步计算。

日期支持 1900—2100 年。取法为大安起正月、月上起初一、日上起子时，依次顺行；闰月按同名月份处理，不额外增加一个月。

## 复制与导出

| 操作 | 位置 | 输出 |
| --- | --- | --- |
| 复制排盘 | 八字、紫微、梅花、小六壬结果底部 | 排盘文字；需要折叠区块内容时，先展开再复制 |
| 修改输入 | 上述四门结果底部 | 回到输入区域；实际更改输入后，再提交生成新结果 |
| 保存结果图片 | 六爻结果底部 | 固定 `1440 × 1920` PNG 结果摘要；支持文件分享的浏览器会打开系统分享面板，否则下载图片 |
| 复制 AI 解读提示词 | 六爻结果底部 | 问题、真实排盘数据与供外部使用的提示词；该操作仅复制，不会调用 AI 或发送数据 |

六爻导出图片包含本卦、变卦、动爻、六爻明细、月建与日辰等摘要，问题文本只截取前 28 个字符；它不是完整网页长图或历史备份。要保留完整问题和规则数据，可复制提示词文字。

目前没有整库导入、导出或跨设备同步功能。分享一条结果的页面链接不会把本机历史带给接收者；需要分享时，请复制文字或导出六爻结果图片。

## 历史记录与外观

点击页面底部“记录”，或打开右上角菜单选择“历史记录”。记录按时间倒序排列；点击记录恢复输入与排盘，点击单条记录的删除按钮可删除，点击“清空记录”可清除所有记录。删除与清空均有确认提示。

六爻最多保留最近 50 条；其余四门共用另一组最近 50 条。记录仅属于当前浏览器与当前站点地址：清除站点数据、换浏览器、换设备或换域名后不会自动恢复。若浏览器阻止保存，页面会显示保存失败提示。

右上角日月图标切换浅色 / 深色主题；也可在菜单底部切换。默认浅色，选择会保存在当前浏览器。系统启用“减少动态效果”后，页面会减少非必要动画。

## 结果与参考排盘不一致时

先核对公历 / 农历、时间、性别、换日、闰月与流年口径。不同流派可能使用不同规则；玄枢会在结果中注明当前取法和规则版本。反馈时请使用虚构或脱敏输入，并附上双方结果、具体差异和参考依据，详见 [贡献指南](../CONTRIBUTING.md)。
