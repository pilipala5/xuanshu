# 计算口径与复现样例

本页记录玄枢当前代码采用的计算约定。不同流派可能使用不同的节气、换日、闰月或流年取法；核对结果时，先确认输入与这些约定一致。

规则计算在浏览器中执行，不调用 AI。以下样例来自项目规则引擎，使用公开测试日期，不对应个人资料。

## 输入范围

| 工具 | 输入 | 范围与说明 |
| :--- | :--- | :--- |
| 六爻 | 所问之事；六次三钱投掷 | 记录原始六爻值、起卦时间与时区；爻序自初爻向上爻 |
| 四柱八字 | 公历日期、HH:mm、性别、换日规则、流年年份 | 日期 1900—2100 年；流年从出生公历年到 2100 年 |
| 紫微斗数 | 公历日期、HH:mm、性别；可选流年年份 | 日期与流年 1900—2100 年；流年不能早于出生农历年 |
| 梅花易数 | 第一数、第二数 | 两个 1—999999 的整数 |
| 小六壬 | 公历日期、HH:mm | 日期 1900—2100 年；时间 00:00—23:59 |

不存在的日期、缺失字段与越界时间会被拒绝。修改输入后，页面清除旧结果，需要重新提交排盘。

## 六爻

- 使用三钱法六次投掷，从初爻到上爻形成原始爻值。
- 原始爻值为 6、7、8、9；6 为老阴、9 为老阳，属于动爻；变卦将 6 变为阳、9 变为阴。
- 展示本卦、变卦、八宫、宫序、世应、纳甲、六亲、六神、月建、日辰与旬空。
- 月建由 `lunar-typescript` 精确节气计算，历法时刻使用固定 UTC+8。
- 日辰使用起卦会话的时区，与页面显示的当地日期一致；完整数据中保留时区与规则版本。
- 动画读取已经锁定的投掷结果；随机源可注入 seed 或 mock，便于复算和测试。

问题文字不参与卦象运算。同一问题再次起卦会产生新的随机投掷；复算同一条记录时，应核对保存的原始六爻值、时间与时区。

结果图片由真实排盘数据生成，为固定 1440 × 1920 的 PNG 摘要，问题文本取前 28 个字符。复制解读提示词保留完整问题与结构化排盘文本，不调用或向 AI 服务发送数据。

源码：[规则引擎](../features/liuyao/engine/index.ts)、[领域模型](../features/liuyao/domain/types.ts)。

## 四柱八字

使用 `lunar-typescript` 排四柱、起运、大运与流年。

| 项目 | 当前约定 |
| :--- | :--- |
| 输入时区 | 固定北京时间 UTC+8；未根据出生地点校正 |
| 年柱、月柱 | 依节气换界；年柱以立春为界 |
| 日柱 | 默认 00:00 换日；可选择 23:00 换日 |
| 晚子时时柱 | 23:00—23:59 沿用依赖的次日子时规则，两种日柱换日选择均如此 |
| 十神、藏干十神 | 以日主为参照 |
| 五行计数 | 四柱八个表层干支各按本气记 1 次；不加藏干权重，不代表旺衰或喜用神 |
| 大运 | 展示前八段大运及其虚岁、公历年范围；起运时间由依赖计算 |
| 流年 | 返回所选年份的干支、十神、藏干、旬空与对应大运；干支按立春换年 |
| 虚岁 | 按所选公历年份与出生公历年份计算；大运按年度范围展示 |

支持胎元、命宫、身宫、纳音、十二长生与旬空。旧记录没有流年字段时，以出生年份补全，避免恢复结果随设备当前年份变化。

**复现样例**

```text
公历日期：1990-06-15
出生时间：12:00（北京时间）
性别：男
子时换日：00:00
流年：2026

四柱：庚午 / 壬午 / 辛亥 / 甲午
日主：辛
流年干支：丙午
```

当前规则版本：`xuanshu-bazi-v2-lunar-typescript`。源码：[八字引擎](../features/bazi/engine/index.ts)。

## 紫微斗数

使用 `iztro` 安星，展示本命十二宫与可选年度叠盘。

| 项目 | 当前约定 |
| :--- | :--- |
| 输入时间 | 按输入的钟表日期、时间取时辰；无出生地 / 真太阳时校正 |
| 闰月 | 初一至十五按当月，十六日起按下月 |
| 新盘晚子时 | 23:00—23:59 先推进完整公历日期，再以次日早子时安星；支持月末与年末换日 |
| 旧版晚子记录 | 保留旧取法，页面明确标注；不静默套用新规则 |
| 生年四化 | 由本命盘计算，与流年四化分别展示 |
| 流年换年 | 农历正月初一 |
| 年度参考日 | 所选公历年的 7 月 1 日；虚岁与大限 / 童限对应此日 |

展示主星、辅星、杂曜、星曜亮度、命主、身主、五行局与十二宫详情。填写流年年份后叠加流年宫位、四化、星曜和大限信息；留空时仅展示本命盘。

年度视图不是任意日期的流月、流日或流时排盘。

**复现样例**

```text
公历日期：1990-06-15
出生时间：12:00
性别：男
流年：2026

五行局：火六局
命主：贪狼
身主：火星
命宫、身宫地支：子
流年干支：丙午
流年参考日：2026-07-01
```

新盘规则版本：`xuanshu-ziwei-v3-calendar-rollover`。保留旧晚子取法的记录使用 `xuanshu-ziwei-legacy-late-zi`。源码：[紫微引擎](../features/ziwei/engine/index.ts)。

## 梅花易数

当前实现双数起卦：

1. 第一数除以 8 取余，余 0 作 8，确定上卦。
2. 第二数除以 8 取余，余 0 作 8，确定下卦。
3. 两数之和除以 6 取余，余 0 作 6，确定动爻。
4. 互卦取本卦二、三、四爻为下卦，三、四、五爻为上卦。
5. 动爻所在的三爻卦为用卦，另一卦为体卦；改变动爻得到变卦。

八卦数序：乾 1、兑 2、离 3、震 4、巽 5、坎 6、艮 7、坤 8。爻序自下向上。仅生成数起卦与体用结构，不生成吉凶文案。

**复现样例**

```text
第一数：17 → 乾（上卦）
第二数：28 → 震（下卦）
两数合计：45 → 三爻动

本卦：天雷无妄
互卦：风山渐
变卦：天火同人
体卦：乾
用卦：震
```

规则版本：`xuanshu-meihua-two-number-v1`。源码：[梅花引擎](../features/meihua/engine/index.ts)。

## 小六壬

按输入的公历钟表日期与时间转换农历月、日和时辰，使用月、日、时逐步落宫：

1. 从大安起正月，顺推到农历月，确定月宫。
2. 从月宫起初一，顺推到农历日，确定日宫。
3. 从日宫起子时，顺推到输入时辰，确定最终落宫。

六宫次序：**大安 → 留连 → 速喜 → 赤口 → 小吉 → 空亡**，循环顺行。闰月按同名月份处理，不另增一个月；页面展示是否为闰月及每一步的顺推步数。

只完成机械落宫与基本六宫信息展示，不生成扩展断语。

**复现样例**

```text
公历日期：2026-10-01
钟表时间：12:00
农历：八月廿一
时辰：午

定月宫：从大安起正月，顺行 7 步 → 留连
定日宫：从留连起初一，顺行 20 步 → 赤口
定时宫：从赤口起子时，顺行 6 步 → 赤口
最终落宫：赤口
```

规则版本：`xuanshu-xiaoliuren-month-day-hour-v1`。源码：[小六壬引擎](../features/xiaoliuren/engine/index.ts)。

## 历史恢复与当前边界

六爻保存完整会话与结果；其余四门保存输入、摘要和规则版本，恢复记录时复算。当前代码对旧版紫微晚子记录保留兼容取法，但不对所有未来版本变动承诺完全一致的历史结果。

当前未实现出生地 / 真太阳时校正、旺衰喜用神判断、自动预测文案或 AI 解读服务。计算结果用于传统文化学习与个人参考，不构成对术数预测有效性的承诺。

报告结果差异时，请提供脱敏输入、规则版本、所选换日 / 闰月等约定、实际结果、预期结果与可核对的参考依据。规则测试位于 [tests/](../tests/)。
